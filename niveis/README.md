# Níveis

Material de aula organizado **por nível**, não por turma. As aulas daqui são
minhas — eu decido o que entra em cada uma. Qualquer turma do nível usa a mesma
sequência.

| Trilha | Níveis |
|---|---|
| CtrlKids | [CK1](CK1/) · [CK2](CK2/) · [CK3](CK3/) · [CK4](CK4/) |
| CtrlTeens | [CT1](CT1/) · [CT2](CT2/) · [CT3](CT3/) · [CT4](CT4/) |
| CtrlYoung | [CY1](CY1/) · [CY2](CY2/) · [CY3](CY3/) · [CY4](CY4/) |

## Criar uma aula

```bash
cp -r docs/class/aula-pratica niveis/<NÍVEL>/<NN>-nome-da-aula
```

Depois, adicione a linha na tabela do `README.md` do nível.

O material antigo, por turma, continua em [`../turmas/`](../turmas/) sem mudança.
