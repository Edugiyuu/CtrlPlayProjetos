# Jogo da Forca — reforço de loop e lista

Aula extra para a turma #10671 (Enzo, Eric, Lucas Basso, Lucas Borges), fora
da numeração do cronograma oficial, entre a aula #5 (repetição) e a aula #6
(dicionários/tuplas/sets/booleanos).

Vocês já viram `while`, `for`, listas e condicionais. Esta aula não traz
matéria nova — é para treinar isso de verdade, construindo um jogo da forca
no terminal do zero.

## O que você pratica

- `while` controlando o loop principal do jogo.
- Lista: guardar e atualizar as letras já reveladas da palavra secreta.
- `for` / `range` para percorrer a palavra posição por posição.
- Comparação de strings e condicionais para decidir vitória/derrota.

## Como rodar

```bash
python forca.py
```

(você mesmo cria o `forca.py` — não existe um arquivo pronto pra editar).

## Como fazer

1. Leia `desafio-forca.md`.
2. Faça o Aquecimento de 5 min.
3. Siga o "O que fazer" — ele diz o quê construir e em que ordem, mas a
   sintaxe Python é com você.
4. Teste contra o CHECK.
5. Só depois de terminar (ou travar de verdade), compare com
   `gabarito/forca.py`.
