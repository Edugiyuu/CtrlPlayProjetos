### O jogo: "A Vila e a Caverna"

Um monstro tomou a caverna e a vila ficou sem água. O chefe da vila pede
ajuda; o herói atravessa a floresta, vence o monstro e volta — e a vila reage
diferente. Usa **só os assets do projeto `Default`**, nenhuma arte extra.

### Duas coisas que não podem ser esquecidas

1. **O projeto mora no navegador daquele PC** (IndexedDB). Toda aula termina
   com `File > Export project...` (`CTRL + E`) e o `.zip` no pendrive/Drive do
   aluno. Aula seguinte começa com `File > Import project...` se o projeto não
   estiver em *Recent projects*.
2. **A interface é em inglês.** Cada aula tem `CARTAO-DE-MEMORIA.md` com a
   tradução dos termos usados naquele dia — é o arquivo que fica aberto do
   lado dele.
